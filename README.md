# Syndex

**Student Assignment and Study Planner with Canvas Calendar Integration**

Syndex is a web-based academic productivity application designed to help university students organize assignments, track progress, manage priorities, and generate study schedules based on deadlines and availability.

The application will combine assignments imported from Canvas with manually entered tasks into a unified dashboard.

## Planned Features

- **Canvas Integration:** Import assignments and deadlines using a Canvas ICS calendar feed.
- **Task Management:** Create, view, edit, and delete academic tasks.
- **Progress Tracking:** Track completion statuses and calculate progress percentages.
- **Priority Management:** Assign task priorities and estimated completion times.
- **Study Scheduler:** Generate suggested study sessions based on deadlines, priorities, and available study time.
- **Unified Dashboard:** View assignments, progress, priorities, and schedules in one place.
